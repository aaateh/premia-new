# Форма «Заявка на партнёрство»

Отдельный прототип формы **«Стать партнёром»**.
Сделан по образцу формы на smmconfa.ru: те же поля, Яндекс SmartCaptcha, отправка
на `info@smmconfa.ru` через SMTP Beget.

Кнопка «Обсудить партнёрство» остаётся в разметке как ссылка на Salebot и форму
не открывает — форма и заголовок у неё общие не нужны.

## Посмотреть

- http://premiya.localhost:8090/partners-form/
- http://127.0.0.1:8090/premiya/partners-form/

Локально виджет SmartCaptcha показывает ошибку домена: превью открывается
на `127.0.0.1:8090`, а в капче разрешён `marketingawards.ru`. На боевом домене
виджет работает.

## Что где

| Файл | Назначение |
|---|---|
| `index.html` | демо-страница и разметка модального окна |
| `partners-form.css` | стили формы |
| `partners-form.js` | открытие/закрытие, маска телефона, валидация, отправка |
| `php/mail_partners.php` | обработчик: проверка капчи и отправка письма |
| `php/config.php` | получатель, тема, отправитель, SMTP |
| `php/config.local.php` | секреты (в `.gitignore`), на сервер загружается рядом с `config.php` |
| `php/PHPMailerAutoload.php`, `php/class.*.php` | PHPMailer |

## Перед боевым запуском

1. В Яндекс SmartCaptcha добавить `marketingawards.ru` и `www.marketingawards.ru`
   в список разрешённых доменов той же капчи, что стоит на smmconfa.ru.
2. Проверить `php/config.php`: тема `marketingawards.ru — Заявка на партнёрство`,
   получатель `info@smmconfa.ru`, отправитель `smmconfa@messengerconf.ru`.
3. Загрузить папку `php/` на сервер рядом с `index.html` (например, `/new/php/`).
4. Указать в форме `action` на путь к обработчику.

## Как встроить в главную страницу

1. Скопировать блок `#partner-form` из `index.html` перед `</body>`.
2. Перенести правила из `partners-form.css` в `css/style.css` (или подключить файл).
3. Подключить `partners-form.js` после `app.js`.
4. Кнопке «Стать партнёром» добавить атрибут `data-partner-open`:

```html
<button class="btn" type="button" data-partner-open>Стать партнёром</button>
```

5. Кнопку «Обсудить партнёрство» не трогаем — она остаётся ссылкой на Salebot
   и форму не открывает.

## Проверки

- Интерфейс: поля, маска, валидация, фокус, Escape, успех — 15/15 сценариев.
- Адаптив 320, 360, 390, 414, 768 и 1024 px — горизонтальной прокрутки нет.
- `php -l` для всех PHP-файлов — синтаксис чистый.
- SMTP-подключение к `smtp.beget.com:465` — успешное.
- Серверный ключ SmartCaptcha принимается Яндексом (тестовый токен → `status: failed`).
- Полный цикл с мок-капчей и мок-SMTP: письмо собирается, тема и получатель верные.
