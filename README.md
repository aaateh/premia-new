# Суровая премия — сайт

Главная премии по ТЗ (`ТЗ сайт премии.md`, версия от 30.10.2026), собранная
на дизайн-системе marketingawards.ru (снята 31.10.2026): тёмная сцена и светлые
бумажные секции, Dela Award, Involve, Golos Award, оранжевый акцент, рамки 1px,
радиус 4px. У главных кнопок — анимация «горящей» рамки из дизайн-системы.
Без теней, градиентов и фоновых эффектов.

Структура, тексты, ссылки и порядок блоков взяты из прототипа без изменений.

## Файлы

```
index.html      — главная: все разделы ТЗ, кроме «Церемонии» и «Результатов»
css/tokens.css  — токены дизайн-системы, шрифты, база
css/style.css   — стили шапки, секций, карточек, кнопок и подвала
js/app.js       — мобильное меню, свёрнутые группы, запуск анимации кнопок
js/star-border.js — canvas-анимация «горящей» рамки кнопок
logo.svg        — рабочий логотип премии (белый + оранжевый #F56624)
fonts/          — 40 бесплатных шрифтов (OFL) + fonts.css + превью
                  подключены Dela Award, Involve и Golos Award
prototypes/     — снимок прототипа от 30.10.2026 (структура без дизайна)
backups/        — копии прототипа и живого сайта
```

## Дизайн-система

| Роль | Значение |
|---|---|
| Фон сцены | `#080607` |
| Светлые секции | бумага `#ECE9E3`, текст `#25292E` |
| Основной текст | `#F5F0EB` на тёмном, `#25292E` на бумаге |
| Вторичный текст | `#C8C2BC` на тёмном, `#4A4D48` на бумаге |
| Рамки | `#C8C2BC` (кнопки), полупрозрачные линии у секций |
| Акцент | `#FF7B39` на тёмном, `#8A2412` на бумаге — подписи, номера, плюсы, hover |
| Заголовки | Dela Award, 400, капс, трекинг −0.012em |
| Подписи и кнопки | Involve, 400 |
| Основной текст | Golos Award, 16px |
| Кнопки | 54px, радиус 4px, рамка 1px, прозрачный фон, блик по рамке |
| Карточки | 2px рамка, радиус 4px, срезанный правый верхний угол — приём из дизайн-системы Сурового |
| Колонка | 1040px, отступ от края `clamp(24px, 4vw, 72px)` |

Светлые токены (`--paper`, `--ink`, `--line`) используются в чередующихся
бумажных секциях; все цвета внутри них инвертированы: текст, рамки, кнопки,
акценты и состояния наведения.

## Доступность

- Контраст текста проверен на живой странице скриптом из skill `accessibility-check`:
  **312 элементов, 0 нарушений AA и 0 нарушений AAA**.
- Мелкие подписи — 12px, вес 600; навигация — 13px, белая; основной текст — 16px.
- Один `h1` (логотип с текстовым именем), иерархия h1 → h2 → h3 без пропусков,
  у всех изображений есть alt, есть ориентиры header/nav/main/footer и `lang="ru"`.
