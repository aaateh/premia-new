# Суровая премия — прототип сайта

Прототип по ТЗ (`ТЗ сайт премии.md`, версия от 30.10.2026): только структура блоков,
тексты и сетка. Чёрный текст на белом, без дизайна и графики. Адаптив под мобильные есть.

## Файлы

```
index.html    — главная: все разделы ТЗ, кроме «Церемонии» и «Результатов»
css/style.css — стили прототипа
js/app.js     — мобильное меню + свёрнутые группы номинаций на мобильных
```

Страницы «Жюри» нет (по решению заказчика): блок жюри — на главной, карточки-заглушки.

## Структура главной (по новому ТЗ)

1. Шапка: логотип, меню (О премии, Номинации, Стоимость, Стать партнёром, Контакты), кнопка «Подать заявку»
2. Первый экран: «Суровая премия», подзаголовок «Получи свой Оскар в маркетинге», описание, даты, кнопка
3. О Суровой премии
4. Миссия — «Сильная работа заслуживает признания»
5. Принципы — «Победу нельзя купить»
6. Для тех, кто делает маркетинг (3 карточки)
7. Зачем участвовать (4 карточки) + «Выбрать номинацию»
8. Номинации: 5 направлений (14 + 11 + 18 + 11 + 9 = 63), у каждого кнопка, блок «Не уверены, какую номинацию выбрать?»
9. Стоимость: 9 900 ₽ / 24 900 ₽, с 19 ноября 11 990 ₽ / 27 990 ₽, «Планируете несколько заявок?»
10. Как представить работу: 5 шагов + важное примечание про кейс
11. Ключевые даты: 4 этапа (шорт-лист 18.03–14.04.2027, финал до 21.04.2027)
12. Экспертное жюри: карточки-заглушки
13. От участия к признанию: 3 карточки
14. Партнёры: место под логотипы + «Станьте партнёром»
15. Организаторы: команда Сурового Питерского форума
16. Вопросы и ответы: 19 раскрывающихся вопросов
17. Контакты: телефон, почта, каналы, кнопка «Обсудить участие»
18. Подвал: логотип, разделы, документы, реквизиты
