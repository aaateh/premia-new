# Фон «Суровой премии» на PHP

Копия сцены с [marketingawards.ru](https://marketingawards.ru/): живой огонь,
искры и кнопка паузы. Сверху — шапка и первые два тёмных экрана из
[/new/](https://marketingawards.ru/new/): первый экран и «О премии».

Огонь показывается **только после полной загрузки ролика**: пока файл
качается, фон чёрный, без рывка на недогруженном видео. Если устройство
слабое, включена экономия трафика или `prefers-reduced-motion` — остаётся
просто чёрный фон.

## Запуск локально

Отдельный сервер поднимать не нужно: папка проекта уже зарегистрирована
в общем dev-server как `premiya`, PHP он выполняет сам.

- тест с шапкой и двумя экранами — **<http://premiya.localhost:8090/php/>**
- чистый полигон фона — <http://premiya.localhost:8090/php/bare.php>

Если dev-server не запущен: `~/.config/dev-server/dev-server start`.

## Параметры

| Адрес | Что делает |
|---|---|
| `/php/` | шапка + два экрана, полное 4K, огонь после полной загрузки |
| `/php/?quality=1440` | тот же кадр, но ролик 1440×760 (3,4 МБ) |
| `/php/?speed=0.7` | скорость огня (0,35–1,5); то же делает бегунок внизу слева |
| `/php/?fire=off` | принудительно чёрный фон — посмотреть запасной вариант |
| `/php/?debug=1` | панель: профиль, вес, ход загрузки |
| `/php/bare.php` | только фон, без контента |
| `/php/bare.php?still=1` | только постер, без ролика |

## Что внутри

```
index.php              шапка и два экрана из /new/ поверх огня
bare.php               полигон: только сцена
inc/config.php         профили качества, пути к роликам, скорость
assets/fire.css        сцена, искры, кнопка паузы, панель отладки
assets/landing.css     поправки для страницы с контентом (приглушение огня,
                       проблеск по слогану)
assets/slogan.js       +7 % слогана на телефоне, если строка влезает
assets/bare.css        полноэкранная подложка полигона
assets/background.js   проверка устройства, полная загрузка, выбор ролика,
                       пауза во вкладке, canvas-искры
assets/*.mp4, *.jpg    сам фон: бесшовные циклы и постеры
tools/loop.sh          сборка бесшовной петли из исходного ролика
```

## Вес фона

| Вариант | Видео | Постер |
|---|---|---|
| Полное 4K (по умолчанию) | 4096×2160, 26,3 МБ | 4096×2160, 136 КБ |
| Облегчённый `?quality=1440` | 1440×760, 3,4 МБ | 1440×760, 30 КБ |
| Телефон | 540×1080, 412 КБ | 540×1080, 19 КБ |

Оба десктопных варианта — один и тот же кадр, меняется только резкость.
Плюс оригинал подгружал запасную картинку `fire-autoplay-wide.webp` на
5,6 МБ — здесь её заменяет постер.

## Скорость и петля

- Внизу слева — бегунок «Скорость огня»: 0,35–1,5 с шагом 0,05, по
  умолчанию 0,70. Значение сразу меняет `playbackRate` и сохраняется
  в адресе (`?speed=0.8`), так что ссылку можно передать или открыть заново.
- Петля бесшовная: последние 1,25 с десктопного ролика (0,5 с телефонного)
  перетекают в начало по перекрёстному затуханию, поэтому на стыке нет
  скачка. Длина цикла: 17,5 с на десктопе и 3,5 с на телефоне.
- Пересобрать петлю из исходника: `php/tools/loop.sh` (trim + xfade + concat),
  команды — в разделе «Как пересобрать ролики».

## Слоган

- На телефоне слоган крупнее на 7 %, но только если верхняя строка
  «Получи свой Оскар» влезает по ширине: `slogan.js` меряет её после
  загрузки шрифта и добавляет класс. Если не влезает — остаётся базовый
  размер.
- По слогану слева направо пробегает красный блик: белый слой держит
  цвет текста, поверх идёт полоса огненного отблеска (background-clip:
  text). Полоса широкая и идёт слева направо; цикл 12 с, сам пробег —
  5,4 с. При reduced-motion анимация выключена.

## Как ведёт себя огонь

1. Проверка устройства: `saveData`, `2g`/`slow-2g`, 2 ядра и меньше,
   2 ГБ памяти и меньше, `update: slow`, нет поддержки MP4, reduced-motion.
   Любое условие — чёрный фон, ролик не скачивается вообще.
2. Ролик качается целиком через `fetch` (с прогрессом в `?debug=1`),
   затем подставляется в `<video>`; проявление (1,4 с) стартует только
   после первого декодированного кадра, поэтому 4K не «прыгает».
3. Играет без звука в цикле; в скрытой вкладке ставится на паузу.
4. Искры (70 частиц, параметры оригинала) включаются вместе с огнём и
   замирают на паузе. На странице с контентом огонь приглушён до 40 %,
   чтобы текст оставался читаемым.
5. Если автозапуск запрещён, показывается первый кадр и кнопка запуска.
6. На телефоне (до 600 px, портрет) — отдельный вертикальный ролик.

## Как встраивать

```php
<?php $config = require __DIR__ . '/inc/config.php'; ?>
<link rel="stylesheet" href="/php/assets/fire.css">
<div class="fire-scene fire-scene--dim" data-fire-scene data-wait="full">
    <div class="fire-media">
        <video class="fire-video" muted loop playsinline preload="auto"
               data-src-desktop="..." data-src-mobile="..."></video>
    </div>
    <canvas class="fire-sparks" aria-hidden="true"></canvas>
</div>
<div class="site"><!-- контент --></div>
<script src="/php/assets/background.js" defer></script>
```

Сцена занимает весь экран (`position: fixed; inset: 0`) и не перехватывает
клики. Контент лежит в обёртке `.site` с `z-index: 1`. Убрать `data-wait="full"`
— и ролик будет играть сразу, без ожидания полной загрузки.

## Как пересобрать ролики

Исходник — `fire-tall-4k-v3.mp4` (23 МБ) и `fire-mobile-portrait-v2.mp4`
с marketingawards.ru.

Бесшовная петля и нужный размер одной командой:

```bash
# полное 4K: хвост 1,25 с перетекает в начало
php/tools/loop.sh fire-tall-4k-v3.mp4 fire-desktop-4k-loop.mp4 1.25 18

# облегчённый: тот же цикл, ширина 1440
php/tools/loop.sh fire-tall-4k-v3.mp4 fire-desktop-1440-loop.mp4 1.25 26 1440

# телефон: 0,5 с на цикл
php/tools/loop.sh fire-mobile-portrait-v2.mp4 fire-mobile-540-loop.mp4 0.5 23
```

Пропорции 4096×2160 сохранены, поэтому при `object-fit: cover` кадр
совпадает с оригиналом — меняется только резкость и длина цикла.
