# Прототип от 30.10.2026

Снимок рабочей версии прототипа главной страницы Суровой премии на 30 октября 2026.
Тексты и структура — по ТЗ (версия от 30.10.2026). Чёрный текст на белом, без дизайна.

## Что внутри

```
index.html    — главная: все разделы ТЗ, кроме «Церемонии» и «Результатов»
css/style.css — стили прототипа
js/app.js     — мобильное меню, свёрнутые группы номинаций на мобильных
```

Страницы «Жюри» в этой версии нет — блок жюри на главной.

## Как посмотреть

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
cd prototypes/2026-10-30
python3 -m http.server 8766
```
