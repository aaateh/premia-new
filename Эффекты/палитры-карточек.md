# Палитры голографических карточек

Два варианта фона, которые делали для блока «Участники». Логика взята с билета
Uiverse (dexter-st / slippery-bird-76): **серебряная подложка + цветные лучи +
слой перелива**, а не просто градиент.

Оба варианта — для светлых (бумажных) секций: текст на карточке тёмный.

---

## 1. Прошлый вариант — пастельный голографик

Холодное серебро, розово-бирюзовые лучи.

| Слой | Значение |
|---|---|
| Серебро | `linear-gradient(135deg, #FFFFFF 0%, #C6C6C0 26%, #F4F4EF 48%, #B8B8B2 72%, #ECECE6 100%)` |
| Лучи | `conic-gradient(from 0deg, #C9C9C4, #FF6BFE, #00F9F8, #E4E4DE, #0081FD, #EEF0BC, #0081FD, #FF6BFE, #C9C9C4)` |
| Наложение лучей | `mix-blend-mode: overlay`, `opacity: .62`, `blur(18px)` |
| Вращение | 8 секунд, линейно |
| Слой перелива | `difference`, `rgba(255,0,80,.18)` → `rgba(255,0,0,.08)` → `rgba(0,255,0,.14)` → `rgba(255,0,80,.18)`, сдвиг 5 с alternate |

```css
.card__silver {
  background: linear-gradient(135deg, #FFFFFF 0%, #C6C6C0 26%,
              #F4F4EF 48%, #B8B8B2 72%, #ECECE6 100%);
  filter: url(#card-bump);
}

.card__holo {
  background: conic-gradient(from 0deg,
    #C9C9C4, #FF6BFE, #00F9F8, #E4E4DE, #0081FD,
    #EEF0BC, #0081FD, #FF6BFE, #C9C9C4);
  filter: blur(18px);
  mix-blend-mode: overlay;
  opacity: .62;
  animation: aurora-spin 8s linear infinite;
}

.card__aurora::after {
  background: linear-gradient(180deg,
    rgba(255, 0, 80, .18),
    rgba(255, 0, 0, .08),
    rgba(0, 255, 0, .14),
    rgba(255, 0, 80, .18));
  background-size: 100% 300%;
  mix-blend-mode: difference;
  animation: aurora-shift 5s ease-in-out infinite alternate;
}
```

## 2. Новый вариант — огонь

Тёплое шампанское серебро, лучи оттенков пламени: золото, оранжевый, алый,
тёмный уголь.

| Слой | Значение |
|---|---|
| Серебро | `linear-gradient(135deg, #FFFDF8 0%, #E3D6C2 26%, #F8F0E3 48%, #D6C3A8 72%, #F3E9DA 100%)` |
| Лучи | `conic-gradient(from 0deg, #E3D6C2, #FFE08A, #FF7A18, #C21E00, #FFB347, #FF4D00, #7A1E00, #FFC46B, #E3D6C2)` |
| Наложение лучей | `mix-blend-mode: normal`, `opacity: .58`, `blur(12px)` |
| Вращение | 8 секунд, линейно |
| Слой перелива | `overlay`, `rgba(255,170,70,.26)` → `rgba(230,60,10,.16)` → `rgba(255,210,120,.24)` → `rgba(255,120,30,.26)`, сдвиг 5 с alternate |

```css
.card__silver {
  background: linear-gradient(135deg, #FFFDF8 0%, #E3D6C2 26%,
              #F8F0E3 48%, #D6C3A8 72%, #F3E9DA 100%);
  filter: url(#card-bump);
}

.card__holo {
  background: conic-gradient(from 0deg,
    #E3D6C2, #FFE08A, #FF7A18, #C21E00, #FFB347,
    #FF4D00, #7A1E00, #FFC46B, #E3D6C2);
  filter: blur(12px);
  mix-blend-mode: normal;
  opacity: .58;
  animation: aurora-spin 8s linear infinite;
}

.card__aurora::after {
  background: linear-gradient(180deg,
    rgba(255, 170, 70, .26),
    rgba(230, 60, 10, .16),
    rgba(255, 210, 120, .24),
    rgba(255, 120, 30, .26));
  background-size: 100% 300%;
  mix-blend-mode: overlay;
  animation: aurora-shift 5s ease-in-out infinite alternate;
}
```

## Общая разметка и каркас

```html
<article class="card participant-card">
  <span class="card__aurora" aria-hidden="true">
    <span class="card__silver"></span>
    <span class="card__holo"></span>
  </span>
  ...содержимое карточки...
</article>
```

```css
.card__aurora {
  position: absolute;
  inset: 0;
  z-index: 0;
  overflow: hidden;
  border-radius: var(--radius);
  clip-path: polygon(0 0, calc(100% - 72px) 0, 100% 60px, 100% 100%, 0 100%);
  pointer-events: none;
  isolation: isolate;
}

.card__silver,
.card__holo { position: absolute; inset: 0; }

.card__holo {
  inset: auto;
  left: 50%;
  top: 50%;
  width: 170%;
  aspect-ratio: 1;
  margin: -85% 0 0 -85%;
  will-change: transform;
}

.card__aurora::after {
  content: "";
  position: absolute;
  inset: 0;
  background-size: 100% 300%;
}

.participant-card > :not(.card__aurora) { position: relative; z-index: 1; }

@keyframes aurora-spin { to { transform: rotate(360deg); } }
@keyframes aurora-shift {
  from { background-position: 0 0; }
  to { background-position: 0 500px; }
}

@media (prefers-reduced-motion: reduce) {
  .card__holo,
  .card__aurora::after { animation: none; }
}
```

Металлическая фактура (фильтр из билета, вставляется один раз в конец `<body>`):

```html
<svg class="svg-filters" aria-hidden="true" focusable="false">
  <filter id="card-bump">
    <feTurbulence result="noise" numOctaves="3" baseFrequency="0.7" type="fractalNoise"></feTurbulence>
    <feSpecularLighting in="noise" result="specular" lighting-color="#fffffc"
      specularExponent="25" specularConstant="0.8" surfaceScale="0.15">
      <fePointLight z="210" y="100" x="100"></fePointLight>
    </feSpecularLighting>
    <feComposite result="noise2" operator="in" in="specular" in2="SourceGraphic"></feComposite>
    <feBlend mode="screen" in2="noise2" in="SourceGraphic"></feBlend>
  </filter>
</svg>
```

```css
.svg-filters { position: absolute; width: 0; height: 0; overflow: hidden; }
```

## Текст на карточке

Для светлой подложки — тёмный текст:

```css
.participant-card {
  --scene-ink: #25292E;
  --scene-muted: #4A4D48;
  color: var(--scene-ink);
}
```

Для тёмной подложки (если понадобится) — светлый:

```css
.participant-card {
  --scene-ink: #F5F0EB;
  --scene-muted: #C8C2BC;
}
```
