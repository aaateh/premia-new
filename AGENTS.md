# Правила проекта «Суровая премия»

## Шрифты: только бесплатные

- **НИКОГДА не использовать платные шрифты** — ни в макетах, ни в прототипах, ни в готовом сайте.
- Разрешены только шрифты со свободной лицензией: **SIL OFL 1.1**, **Apache 2.0**, **MIT**, **CC0**,
  а также любые семейства из **Google Fonts**.
- «Бесплатно для личного использования», «demo», «trial», «EULA» = **платный**. Не использовать.
- **Лицензия не подтверждена = считаем платным.** Без официального подтверждения шрифт в проект не попадает.
- Если в референсе, макете или чужом сайте используется платный шрифт — **подобрать бесплатный аналог**,
  а не тянуть оригинал.
- Перед добавлением любого нового шрифта — сверить его со списком в `ШРИФТЫ.md`
  и проверить метаданные файла (поля `License`, `License URL`, `Copyright`).
- Рядом со шрифтом хранить текст лицензии (`OFL.txt`), изменённые версии не называть
  зарезервированными именами (Reserved Font Names).

Готовый список «можно / нельзя» с файлами и лицензиями: **`ШРИФТЫ.md`**.
